# Security and model-risk policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest tagged
release.

## Reporting a vulnerability

Do not open a public issue for dependency, arbitrary-code-execution, secret
exposure, or supply-chain vulnerabilities. Use GitHub private vulnerability
reporting when enabled, or contact `alpha.toure.kabinet@gmail.com` with:

- the affected commit or release;
- a minimal reproduction;
- expected impact;
- suggested mitigation, when available.

Please allow reasonable time for confirmation and remediation before public
disclosure.

## Financial model risk

This repository is research software. It is not approved for live trading,
pricing, capital allocation, or regulatory reporting. Mathematical, numerical,
or model-risk defects that do not expose systems or secrets should be reported
through the **Scientific or methodological issue** template with a derivation or
minimal reproducible test.
