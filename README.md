**Auditable NumPy implementation and partial replication of deep hedging under transaction costs and stochastic volatility.**

This repository packages the manuscript, mathematical conventions, simulation code,
manual gradients, benchmark calibration, finite-sample CVaR estimator, tests,
experiment configurations, generated outputs, and response to reviewers as one
version-controlled research artifact.

> **Scientific status.** The repository is designed for transparent replication,
> not live trading. Values in `results/legacy/` come from an earlier single-run
> draft and are retained only for provenance. Confirmatory claims must be generated
> from the frozen multi-seed plans in `configs/plans/` and reported with paired
> uncertainty estimates.

## What is implemented

- Exact GBM simulation and a fully specified full-truncation Euler Heston scheme.
- State-only and inventory-aware neural hedging policies in NumPy.
- Manual forward, backward, and recurrent backpropagation routines.
- Linear and quadratic transaction costs with correct cross-time indexing.
- Exact finite-sample empirical CVaR boundary weighting.
- Cost-aware benchmarks: no hedge, Black--Scholes delta, shrinkage, no-trade bands,
  reduced-frequency delta, instantaneous-volatility delta, and Heston diagnostics.
- Validation-only benchmark calibration and paired bootstrap comparisons.
- Reproducible smoke experiments and frozen multi-seed confirmatory plans.
- LaTeX manuscript, figures, contribution statement, and response to reviewers.

## Installation

### Virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
```

### Conda

```bash
conda env create -f environment.yml
conda activate asr-deep-hedging
python -m pip install -e '.[dev]'
```

### Docker

```bash
docker build -t asr-deep-hedging .
docker run --rm asr-deep-hedging
```

## Verification

```bash
make lint
make test
make gradient-check
make smoke
make paper
```

The gradient validator checks both the feedforward policy and the complete
transaction-cost-coupled objective against centered finite differences.

## Run an experiment

```bash
python scripts/run_experiment.py \
  --config configs/smoke_gbm_linear.json \
  --output results/generated/smoke_gbm_linear
```

Inventory-aware policy:

```bash
python scripts/run_experiment.py \
  --config configs/smoke_gbm_inventory.json \
  --output results/generated/smoke_gbm_inventory
```

## Confirmatory campaign

```bash
python scripts/run_plan.py \
  --plan configs/plans/confirmatory_gbm_cost_sweep.json
```

Before launching the confirmatory campaign, freeze the commit, environment,
seeds, validation rule, and output directory as described in
[`docs/reproducibility.md`](docs/reproducibility.md).

## Benchmark calibration

```bash
python scripts/calibrate_benchmarks.py \
  --config configs/confirmatory_gbm_linear_k001.json \
  --output results/generated/benchmark_calibration.json
```

Calibration paths must remain separate from final test paths.

## Heston benchmark surface

```bash
python scripts/precompute_heston_delta.py \
  --config configs/heston_delta_surface_example.json \
  --output results/generated/heston_delta_surface.npz
```

Reference the resulting file through `heston_delta_surface` in a Heston
experiment configuration.

## Reproducibility policy

Every numerical claim intended for the manuscript must include:

1. a committed configuration and deterministic seeds;
2. raw per-seed outputs and software metadata;
3. an explicit validation and checkpoint-selection rule;
4. paired uncertainty estimates on common test paths;
5. regenerated tables, figures, and manuscript;
6. a clean CI run on the exact reported commit.

See [`docs/claims-register.md`](docs/claims-register.md),
[`docs/experiment-matrix.md`](docs/experiment-matrix.md), and
[`docs/release-checklist.md`](docs/release-checklist.md).
